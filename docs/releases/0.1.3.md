# ICOR for Life - PDF Annotation 0.1.3

The plugin follows Scaffold 1.17.0, which renames `04 Inner World/Documents`
to `04 Inner World/Notes`.

- The default highlights folder is `04 Inner World/Notes/Highlights`. An
  install that still holds the old default in its settings is moved to the
  new one on load; a folder you chose yourself is left as it is. Existing
  highlight notes keep working wherever they are.

Needs Obsidian 1.13.0 or newer; verified against the 1.13.7 bundle.
