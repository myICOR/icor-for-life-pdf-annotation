# ICOR for Life - PDF Annotation 0.3.0

The plugin follows ICOR for Life 3.0, which moves Inner World from
`04 Inner World` to `02 Inner World`.

- The default highlights folder is `02 Inner World/Notes/Highlights`. If your
  settings still hold the 2.x default, it stays while your vault still has
  `04 Inner World`, and follows to the new folder once the vault has moved. A
  folder you chose yourself is left as it is. Existing highlight notes keep
  working wherever they are.

Needs Obsidian 1.13.0 or newer. Copy `main.js`, `manifest.json` and
`styles.css` into `<vault>/.obsidian/plugins/icor-for-life-pdf-annotation/`.
