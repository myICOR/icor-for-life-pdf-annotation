# ICOR for Life - PDF Annotation 0.1.2

Hardening after Vex's audit and Flint's review of 0.1.1.

- Deleting a highlight trashes only the PNG the plugin wrote for it, and
  the dialog says when an image will go.
- The highlights folder setting refuses `.` and `..`.
- A highlight id must be a plain token; a link target must be a clean
  path.
- The panel names Cmd or Ctrl by platform, nothing on a phone.
- American spelling throughout.

Needs Obsidian 1.13.0 or newer; verified against the 1.13.7 bundle.
